GOLDEN CRUST BAKERY WEBSITE

Files:
- index.html
- style.css
- script.js
- images/ (optional images folder)

HOW TO RUN:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. For best development, use VS Code + Live Server.

FEATURES:
- Responsive bakery website
- Product hover information
- Add-to-cart system with localStorage
- Quantity controls
- Checkout demo
- Mission/Vision
- History/background
- Hover About Us cards
- Contact form demo
- Google Maps embed
- Dark/light mode

TO CHANGE THE LOCATION:
Open index.html and search for "San Miguel, Iloilo, Philippines".
Replace the map query and displayed address with your real bakery location.

TO ADD REAL PRODUCT PHOTOS:
Replace the emoji inside script.js product data with image elements, or add image files and update the product rendering.
